Privacy Policy

Last updated: 13 November 2026

"Ya Böyle Olsaydı Paylaşım" (the "App") is a personal tool operated by the owner of the TikTok account it posts to. It is used only by its owner.

Data we access

When the owner logs in with TikTok, the App receives an access token and basic account information (display name, username) through TikTok's official API. It uses these only to upload the owner's own videos to the owner's own account.

Data we store

The App stores only an encrypted refresh token so it can keep posting on schedule. It does not collect, sell or share any personal data, and it does not access other users' data, followers, messages or analytics.

Third parties

Data is exchanged only with TikTok's API. The App runs on GitHub Actions.

Deleting data

The owner can revoke access at any time in TikTok settings (Security > Manage app permissions); the stored token then stops working and is deleted.
